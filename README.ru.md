## что умеет

**с Claude Code**

- думает: над головой мигает лампочка
- работает: достаёт ноут и пишет код
- ждёт тебя: машет и мигает «!»
- закончил: подпрыгивает с искрами
- что-то упало: глаза x x и капля пота
- новая сессия: здоровается

**сам по себе** он гуляет по панели задач и следит глазами за курсором, читает, пьёт кофе (утром чаще), делает зарядку, гоняется за бабочкой, залезает на окна и катается на них, иногда прыгает и шлёпается в лепёшку, а если долго не трогать комп, засыпает. всё в случайном порядке и не слишком часто

**с тобой**

- его можно таскать мышкой, в том числе на другой монитор
- погладить: проведи курсором туда-обратно 3 раза
- заморозка: стоит там, куда поставил
- копии: до 8 клодов, которые повторяют за главным

**Spotify** (обычное приложение, премиум не нужен): над головой появляется плеер с обложкой, названием, исполнителем, таймлайном и кнопками, там же mix, повтор (выкл, альбом, трек) и «удиви меня», которая включает волну по текущему треку. сердечко добавляет или убирает трек из любимых, ещё есть список любимых треков с поиском, кликаешь и трек играет

язык русский или английский, переключается в меню

## как поставить

качаешь `Clauddy.zip` из [releases](../../releases), распаковываешь и запускаешь `Clauddy.exe`. нужна винда 10 или 11, 64 бит

exe не подписан, поэтому винда может показать синее окно, жми «подробнее» → «выполнить в любом случае». если не хочешь доверять exe, собери сам, как написано ниже

### подключить к Claude Code

пкм по клоду или по иконке в трее → **подключить к Claude Code**, потом перезапусти Claude Code.
в `~/.claude/settings.json` добавятся http хуки, а старый файл сохранится как `settings.json.clauddy-backup`

хуки шлют события только на `http://127.0.0.1:47613`, то есть на твой же комп, в интернет ничего не уходит.
отключить можно там же, **отключить от Claude Code**

## собрать самому

```powershell
python -m pip install -r requirements.txt
.\build.ps1        # exe будет в dist\Clauddy.exe
```

без сборки: `python clauddy.py`, все кадры анимаций картинкой: `python clauddy.py --preview sprites.png`

## что где лежит

| файл | что там |
|---|---|
| `clauddy.py` | сам клод: спрайты нарисованы кодом, физика, занятия, трей, локальный сервер для хуков |
| `media.py` | Spotify: что играет берётся из винды, любимые через `spotify_cli.exe`, который идёт вместе со Spotify |
| `panel.py` | плеер |
| `picker.py` | список любимых треков |
| `i18n.py` | все тексты интерфейса на русском и английском |
| `make_icon.py` | рисует иконку из тех же спрайтов |

настройки лежат в `%APPDATA%\Clauddy`
